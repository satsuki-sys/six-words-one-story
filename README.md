A make.fun bounty entry: a program that writes one complete story in
exactly six words to `/output/entry.txt`.

## The story

> She sold the piano. Kept practicing.

Six words, 36 characters. The instrument is gone; the habit outlives
it — and the reader is left to fill in why.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Python 3.13 standard library only; no dependencies, no network.
